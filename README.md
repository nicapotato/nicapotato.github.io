# nicapotato.github.io

**Static personal site** (HTML, CSS, and JavaScript). It presents a professional profile: background, projects, and related links in a single-page layout with assets under `css/`, `js/`, `images/`, and `fonts/`.

## User guide

There is no install or build step; open files directly or use a local static server.

| Command | Description |
|--------|-------------|
| `make help` | Show available targets |
| `make serve` | Serve the repo root with Python’s HTTP server (default port 8800) |
| `PORT=3000 make serve` | Same as above on another port |

Requires **Python 3** for `make serve`.
